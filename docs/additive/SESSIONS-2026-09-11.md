# sessões, equipes e Zed · pesquisa documental

## alcance e resultado

pesquisa pública delegada ao Luna, retomada com autorização para effort disponível
(reportado como unknown), sem elevação. nenhuma instalação, execução funcional,
alteração de runtime ou acesso a credenciais. evidência documental/código, não QA.

- OpenCode `1.18.30`: rotas no tag exato oferecem listar sessões, obter detalhes,
  mensagens e filhos, criar/forkar e enviar prompt/prompt_async a um sessionID.
  isso não comprova abrir sessões no Zed nem comunicação autônoma entre agentes.
- Zed/ACP: docs atuais descrevem threads externas e histórico condicionado ao
  suporte do agente. não foi comprovada UI para filhos/equipes OpenCode ou
  mensagens entre threads independentes. ausência de evidência não é impossibilidade.
- Ensemble (main consultado; versão reportada 0.17.0): equipes, dashboard local,
  sessões por membro, tarefas e mensagens. `team_message` exige participação na
  equipe e resolve destinatário como líder ou membro da mesma equipe; não aceita
  sessionID arbitrário. `team_view` também filtra membros da equipe.
  `team_spawn` cria sessão filha e registra membro; não foi encontrado mecanismo
  de descoberta/adoção de sessões arbitrárias preexistentes, inclusive ACP.

**correção da hipótese inicial:** mensagens peer-to-peer do Ensemble não atendem
por si só D-021 (sessões independentes visíveis/acessíveis e com mensagens).
DB compartilhado entre instâncias não remove o vínculo obrigatório à equipe.

## recomendação e pendências

Ensemble é candidato para equipes, não solução comprovada para todo D-021.
compatibilidade real com `1.18.30`, carregamento via ACP/Zed, custos de
dashboard/SQLite/worktrees e restauração visual ainda não foram testados.
a API nativa oferece uma base para investigar integração; não autoriza criar
bridge, instalar plugin ou fazer fork. próxima decisão: priorizar pesquisa de
integração para sessões independentes ou validar primeiro equipes/threads existentes.
nenhuma solução completa pronta foi comprovada nesta pesquisa.
